## Project Overview

nnU-Net v2 based 3D segmentation pipeline for lumbar paraspinal muscles (Erector Spinae and Multifidus). Uses the self-configuring nnU-Net framework for automatic architecture optimization.

**Target**: >95% Dice score on 4-class muscle segmentation (L_ES, R_ES, L_MF, R_MF)

## Evaluation Metrics

Based on lumbar muscle segmentation literature, the following metrics are computed per-class and macro-averaged:

| Metric | Description | Target |
|--------|-------------|--------|
| Dice (DSC) | Overlap coefficient | >0.95 |
| Jaccard (IoU) | Intersection over Union | >0.90 |
| HD95 | 95th percentile Hausdorff Distance (mm) | <5mm |
| ASSD | Average Symmetric Surface Distance (mm) | <1mm |
| Precision (PPV) | Positive Predictive Value | >0.95 |
| Recall (TPR) | Sensitivity / True Positive Rate | >0.95 |
| Specificity (TNR) | True Negative Rate | >0.99 |
| RVE | Relative Volume Error | <0.05 |

References:
- [ScienceDirect: Lumbar muscle segmentation](https://www.sciencedirect.com/science/article/pii/S2950363924000206)
- [Wiley: Paraspinal muscle segmentation](https://onlinelibrary.wiley.com/doi/full/10.1002/jsp2.70003)

## nnU-Net Key Commands

```bash
# Check dataset integrity
nnUNetv2_plan_and_preprocess -d 001 --verify_dataset_integrity

# Train specific configuration
nnUNetv2_train DATASET_ID CONFIG FOLD [-tr TRAINER]
# Example: nnUNetv2_train 001 3d_fullres 0

# Find best configuration after training all folds
nnUNetv2_find_best_configuration 001 -c 3d_fullres

# Predict with trained model
nnUNetv2_predict -i INPUT -o OUTPUT -d 001 -c 3d_fullres -f FOLD

# Export model for deployment
nnUNetv2_export_model_to_zip -d 001 -c 3d_fullres -f all
```

## W&B Logging (Offline Mode)

Both training and evaluation use W&B in offline mode (compute nodes have no internet). After jobs complete:

```bash
# Sync runs from login node (has internet)
./scripts/wandb_sync.sh                           # Sync all runs
./scripts/wandb_sync.sh /path/to/specific/run     # Sync specific run

# Or manually
wandb sync nnUNet_results/Dataset001_LumbarMuscle/nnUNetTrainerWandb__nnUNetPlans__3d_fullres/fold_0/wandb/latest-run
```

**Training metrics logged**: train/loss, val/loss, val/mean_fg_dice, val/dice_L_ES, val/dice_R_ES, val/dice_L_MF, val/dice_R_MF

**Evaluation metrics logged**: All metrics from table above (Dice, HD95, ASSD, etc.) per-class and macro-averaged, plus per-case results table

## Architecture Notes

- **nnU-Net v2**: Self-configuring framework that automatically determines optimal preprocessing, network architecture, and training scheme
- **3d_fullres**: Full resolution 3D U-Net, recommended for this dataset
- **5-fold CV**: Standard nnU-Net uses 5-fold cross-validation for robust evaluation
- **Expected Dice**: 95-97% for muscle segmentation with proper training

## Training Results (Jan 2026)

### Training Completed
- **5-fold cross-validation**: All folds trained to 1000 epochs
- **Trainer**: `nnUNetTrainerWandb` (with W&B logging)
- **Dataset**: 347 subjects (277 train / 70 val per fold)

### Evaluation Results

| Evaluation Method | Macro Dice | L_ES | R_ES | L_MF | R_MF | Notes |
|-------------------|------------|------|------|------|------|-------|
| Per-fold CV | **90.6%** | 91.7% | 91.7% | 89.7% | 89.2% | Unbiased (each fold tests on held-out data) |

### Key Observations
- Multifidus muscles (L_MF, R_MF) are ~2% lower than Erector Spinae (L_ES, R_ES)
- One outlier case with 21% Dice (likely annotation issue)
- HD95/ASSD metrics showing NaN (surface distance calculation issue to debug)
